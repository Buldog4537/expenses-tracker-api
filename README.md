# Expense Tracker API

A backend API built with Python, Django, and Django REST Framework that allows users to manage income, expenses, and budgets.

## Technologies Used

- Python
- Django
- Django REST Framework

## Features

- User registration and authentication
- Create, update, and delete income records
- Create, update, and delete expense records
- Budget tracking
- User-based permissions for financial data

## Project Overview

This project was built to practice developing backend applications with Django REST Framework. It includes user authentication, API development, database relationships, and permission handling to allow users to  manage their own financial records.
